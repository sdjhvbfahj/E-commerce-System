# 621电商 · 运营管理端

与用户端（`../User`）配套的运营管理后台，Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts。

## 启动

```bash
cd Manage
npm install
npm run dev        # 默认 http://localhost:5173
```

其他命令：`npm run build`（类型检查 + 构建）、`npm run type-check`、`npm run preview`

## 权限说明

- 登录返回当前角色的 `permissions: string[]`，存 Pinia 并持久化；
- 路由守卫：未登录跳 `/login`，越权访问跳 `/403`；
- 左侧菜单按权限码过滤（`stores/permissionStore.ts`）；
- 按钮级：`v-permission="'goods:update'"`（支持数组）；
- 在「角色权限」页改完权限，菜单和按钮立刻跟着变。

## 假数据

- 复用用户端的假数据层（`src/mock/`）：商品、分类、品牌、SKU 与用户端展示的是同一批；
- 管理端新增 `data/admin.ts` + `handlers/admin.ts`：角色权限、管理员、会员、库存、流水、退款、内容运营、日志、概览；
- **写操作会真的改数据**并持久化到 localStorage（key：`eshop621-admin-db-v1`），同时自动写操作日志；
- 侧边栏底部「重置演示数据」可一键还原；控制台执行 `__resetMockDb()` 效果相同。

## 与架构文档的差异

验证码、富文本详情、图片上传、批量导入、导出任务中心、会员详情页、日志前后值对比 —— 这些在演示版里未实现，其余均按文档落地。
